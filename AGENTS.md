# Agent Instructions

Read [`.agents/agents.md`](.agents/agents.md) for project context, architecture, and development gotchas before making changes.

## Required Commit and PR Format

Every commit subject and PR title must start with a project domain:

```
<DOMAIN>: <brief summary>
```

Valid domains: `AI`, `UI`, `SETTINGS`, `HISTORY`, `SECURITY`, `DOCS`, `RELEASE`, `BUILD`.

Open a PR for every change, including docs, chores, and small fixes, so the work is recorded. See `.agents/agents.md` for domain definitions and the full workflow.
